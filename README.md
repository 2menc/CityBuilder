# CityBuilder

**CityBuilder** is a city-building and management game developed with [libGDX](https://libgdx.com/).  
The project is designed to deliver a clean, expandable foundation for a strategic simulation game where players grow a settlement into a thriving city.

Start from a small town, plan your urban layout, manage resources, and expand your city step by step. Every decision shapes how efficiently your city develops and how far it can grow.

---

## 🎮 Game Features

- **City construction** — place buildings, expand your settlement, and shape the urban layout.
- **Strategic management** — make decisions that affect growth, efficiency, and progression.
- **Progressive expansion** — develop your city from a small settlement into a larger, more complex urban system.
- **Modular architecture** — organized code structure for easier development and maintenance.
- **Desktop support** — built with libGDX and LWJGL3 for desktop execution.

---

## 🏙️ About the Game

CityBuilder is focused on giving players an accessible but engaging city-building experience.

The goal is not just to place buildings, but to create a functional and well-balanced urban ecosystem:
- optimize building placement,
- support population growth,
- improve city efficiency,
- expand from a basic settlement into a full city.

---

## 🧩 Project Structure

The project is divided into modules:

- **`core`** — contains the main game logic shared across all platforms.
- **`lwjgl3`** — the primary desktop platform using LWJGL3.

---

## 🚀 Requirements

- Java installed
- Gradle Wrapper included in the project
- A desktop environment compatible with libGDX/LWJGL3

---

## ▶️ Running the Project

You can run the game with Gradle:

```bash
./gradlew lwjgl3:run
```

---

## 🛠️ Useful Gradle Tasks

- `build` — compiles the project and creates the output artifacts.
- `clean` — removes build folders.
- `test` — runs unit tests, if any exist.
- `lwjgl3:run` — launches the game.
- `lwjgl3:jar` — builds the runnable jar in `lwjgl3/build/libs`.
